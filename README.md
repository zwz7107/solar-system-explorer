# 太阳系探索 · Solar System Explorer

面向孩子与亲子探索的三维太阳系网页，帮助直观理解天体的空间关系、大小差异与距离尺度。

## 功能

- 太阳、八大行星和14颗卫星，共23个天体；三维近看、天体目录与卫星系统导航。
- 观察比例与真实比例切换：真实比例统一天体半径与距母体中心的轨道距离。
- 任意两颗天体的大小比较，以及八大行星距太阳的线性距离比较。
- 时间流速、暂停、名称/轨道显示、画质切换和中文科普说明。
- 22个天体使用有出处的贴图；土卫六采用霾层示意。所有场景纹理随源码提供。

## 本地开发

已使用Node.js 24验证。在仓库目录执行：

```sh
npm ci
npm run dev
```

开发预览地址：http://127.0.0.1:5173。

## 构建与使用

```sh
npm test
npm run build
npm start
```

生产预览地址：http://127.0.0.1:4173。Windows也可在构建后双击start.cmd。

需要无需Node.js的离线网页时，先构建，再执行：

```sh
node scripts/build-offline.mjs
```

离线生成器将输出独立网页、来源页、说明和许可文件。现有生成器使用固定日期目录，若同名输出已存在会拒绝覆盖。

## 项目结构

```text
src/          三维场景、交互、天文数据与比例计算
public/       天体贴图、素材清单与来源页
tests/        天体目录与比例计算测试
scripts/      启动、离线构建和浏览器验证脚本
docs/         天文数据和纹理来源说明
```
